EF Core Database Structure

Every table the app needs, and how they join up. The C# classes behind these boxes are written out in full in Doc/DataModel.md.

1. How to read this

Each box is one table. PK is the primary key (the row's unique number). FK is a foreign key (a pointer to a row in another table). The crow's foot — the three-pronged end of a line — always sits on the "many" side. So one Process has many Process Steps.

  • Login & security (Identity)
  • People & org structure
  • Processes & steps
  • History & alerts

3c. How work gets done

Three levels, and the order matters at each one. A folder holds processes in sequence — those are the cards in the flow strip. Each process holds steps in sequence — the numbered list underneath. Back and Next walk the steps and cross from one process into the next, so a whole folder reads end to end.

4. Delete rules

What EF Core does to the children when a parent row goes away. Getting this wrong is the classic way to lose a week of data with one click, so the default answer is Restrict — refuse the delete until the children are dealt with.

ParentChildOn deleteWhy
ProcessProcessStepCascadeA step has no meaning without its process
ProcessStepStepOwnerCascadeThe assignment dies with the step
ProcessStepStepImageCascadeSame
AppUserNotificationCascadeNobody else can read them
AppUserActivityLogSetNullKeep the history, forget who
DepartmentEmployeeRestrictMove the staff first
EmployeeStepOwnerRestrictUnassign the person first
DepartmentProcessRestrictThe flow-strip tag - untag before deleting
ProcessFolderProcessRestrictEmpty the folder first
StepStatusProcessRestrictLookup rows are never deleted
StepStatusProcessStepRestrictLookup rows are never deleted

5. Soft delete

Business tables carry an IsDeleted flag. "Deleting" a row sets the flag to true and a global query filter hides it from every query. Nothing is physically removed, so a mistaken delete is one UPDATE away from being undone. The link tables (StepOwner) and the append-only tables (ActivityLog) are exceptions — they are deleted for real, or never deleted at all.
