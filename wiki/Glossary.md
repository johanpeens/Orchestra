# Glossary

Big words, small explanations. They are in A to Z order.

| Word | What it means |
|---|---|
| **Admin** | The boss role. Can do everything, including letting new people in. |
| **API key** | A long secret code that lets a program use another company's service, like a password for programs. Keep it secret. |
| **Approve** | When an admin says "yes, you may come in". |
| **Base64** | A way of turning a picture into plain text so it can be packed inside other text. |
| **Blazor** | A tool from Microsoft for building websites using C# instead of JavaScript. |
| **Bot** | The chat helper that answers questions. |
| **Circuit** | The live connection between your browser and the server in a Blazor Server app. |
| **Database** | Where the app keeps its information so it is still there tomorrow. |
| **Department** | A group of people, like Sales or Accounts. |
| **Employee** | A person listed on the Team page. Not always someone who can sign in. |
| **Entity Framework (EF Core)** | A tool that lets the code talk to the database without writing database commands by hand. |
| **Folder** | The biggest box in Orchestra. It holds processes. |
| **Gemini** | Google's AI. One of the brains the bot can use. |
| **Grounded** | Answering **only** from the facts you gave. A grounded bot does not invent. |
| **Interface** | A list of jobs a piece of code promises to do, without saying how. |
| **JSON** | A way of writing information as text that both people and computers can read. |
| **LocalDB** | A small database that lives on your own computer. |
| **Lockout** | When your account is paused for a while after too many wrong passwords. |
| **Manager** | A role that can create, edit and delete most things. |
| **Member** | A role that can add and update steps. |
| **Migration** | A small instruction that changes the database shape, like adding a new column. |
| **Mock** | A pretend copy used for practice and tests. |
| **MudBlazor** | A set of ready-made buttons, windows and tables for Blazor. |
| **OpenAI** | A company that makes AI. One of the brains the bot can use. |
| **Portal (chat brain)** | The built-in helper that answers from your steps without any internet or key. |
| **Process** | A job written as ordered steps. |
| **Role** | A badge that says what you may do. |
| **Screenshot** | A picture of a screen. Each step can have one. |
| **Secret** | A password or key. Never put it in a shared file. |
| **Seed** | Practice data the app puts in the database the first time. |
| **SMTP** | The way programs send email. |
| **SQL Server** | A popular database program from Microsoft. |
| **Step** | One action inside a process. |
| **Training data** | Everything the bot has been told. |
| **Twilio** | A company whose service lets the bot talk on WhatsApp. |
| **User secrets** | A private place on your computer to keep passwords and keys, outside the project. |
| **Viewer** | A role that can only look and ask the bot. |
| **WhatsApp bot** | The same bot, answering on WhatsApp. Off until you set it up. |
